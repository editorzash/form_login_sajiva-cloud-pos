# Form Login — SAJIVA POS Cloud POS

Halaman portal autentikasi & login resmi untuk **SAJIVA POS** (Artisan Cafe & Roastery).

## Fitur Utama Form Login
1. **Dua Mode Autentikasi**:
   - Mode 1: **Email & Kata Sandi** (dengan fitur intip kata sandi).
   - Mode 2: **PIN Cepat Kasir (6-Digit)** dengan visual dots & virtual numeric keypad layar sentuh.
2. **Akun Demonstrasi 1-Klik**:
   - 👑 **Super Admin / Owner**: `superadmin@sajiva.co` (PIN: `123987`)
   - 💼 **Manajer Operasional**: `roaster@sajiva.co` (PIN: `456123`)
   - 💳 **Kasir Shift**: `barista@sajiva.co` (PIN: `123456`)
3. **Pemilihan Cabang / Outlet Aktif** (Sajiva Kemang Roastery, Sajiva Menteng, Sajiva Canggu).
4. **Indikator Live Status**: Menampilkan status konektivitas server secara interaktif.
5. **Auto Redirect**: Setelah autentikasi berhasil, pengguna langsung diarahkan ke aplikasi utama di [`../sajiva-cloud-pos/index.html`](../sajiva-cloud-pos/index.html).
6. **Bypass Button**: Tombol shortcut untuk penguji/developer membuka aplikasi tanpa proses login.

## Menjalankan Halaman
Cukup buka file `index.html` langsung di browser Anda (atau via server lokal / GitHub Pages).
